    How recommendations work

    Each recommendation looks at the last time you did that exercise and applies a few rules drawn from hypertrophy research. The studies report group averages, mostly from young adults, so treat the numbers as a starting point and adjust to how you feel. Skip any set that hurts.

    Rep ranges

    Muscle growth is similar across a wide range of loads when sets end close to failure1. The app uses fixed ranges so progress is easy to compare from week to week:

    Exercise typeRepsExample
    Heavy compound6–10Barbell squat, bench press, pull-up
    Compound8–12Leg press, pulldown, dumbbell press
    Isolation10–15Curls, lateral raises, leg curls

    Effort

    Growth tends to increase as sets end closer to failure2, but going all the way to failure was not clearly better than stopping just short3. Aim to finish each set with 1–3 reps left. The optional “reps left” answer uses the reps-in-reserve scale10; if you say 4 or more, the app treats the weight as too light.

    Adding weight or reps

    The app uses double progression. Keep the weight and add a rep to each set. Once every set reaches the top of the range, the weight goes up about 2.5% for upper-body and small-muscle exercises, or 5% for lower-body compounds, rounded up to the smallest plate or dumbbell step. The ACSM recommends a 2–10% increase once you can do 1–2 reps more than your target on two sessions in a row4. This app moves a little sooner, after one session where every set reaches the top of the range. When the smallest step is more than 10% (light dumbbells, for example), it has you add two extra reps first. Adding reps builds muscle about as well as adding weight5.

    Too heavy or fading

    If your first set falls below the range, the weight drops to one that should land in range, using the Epley one-rep-max estimate (weight × (1 + reps ÷ 30)). If only the later sets fall short, those get about 10% less weight, plus a reminder to rest 2–3 minutes. In trained men, 3-minute rests produced more quad growth than 1-minute rests6. If you make no rep gains at the same weight for 3 sessions, the app suggests dropping about 10% and building back up. That reset is a rule of thumb, not a study finding.

    Number of sets

    Sets are counted per muscle, with 1 for each set where the muscle is a main mover and 0.5 where it helps. That “fractional” count predicted growth best in a large meta-regression7, and the diagram uses the same count. If a muscle’s last 7 days plus today’s plan comes to under 10 sets, the app adds a set (up to 4 per exercise), because about 10 or more weekly sets per muscle was linked to more growth8. Above 20 it removes one, since returns shrink at higher volumes7.

    Upper and lower days

    The plan alternates upper and lower body, so most muscles get trained about twice a week. Training a muscle twice a week beat once a week in a meta-analysis9, though when total weekly sets are equal, frequency makes little difference7. The plan repeats your last session of that type in the same order. It then adds an exercise for any muscle in that half of the body that is still barely trained this week. With no history, it starts from a standard template.
